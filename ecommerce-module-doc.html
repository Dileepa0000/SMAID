E-Commerce Module

Shopify & WooCommerce Integration

Connect your store to WhatsWay to automate customer communication, recover abandoned carts, and trigger WhatsApp messages from order events.

01 Overview

The E-Commerce Module enables users to connect their online stores with WhatsWay and automate customer communication through WhatsApp. It supports customer synchronization, abandoned cart recovery, and order-based automation.

Supported Platforms

shopify woocommerce

Key Features

  • Shopify & WooCommerce Integration
  • Multi-Store Support
  • WhatsApp Order Notifications
  • COD Verification System
  • Abandoned Cart Recovery
  • Customer Synchronization
  • Order Automation
  • Automatic Webhook Registration
  • Analytics Dashboard

02 Store Connection

Shopify

Shopify uses OAuth. The Superadmin configures the Shopify app credentials once, and users only enter their store URL to connect.

Superadmin Settings

  1. Open Superadmin → Settings → E-Commerce → Shopify
  2. Enter the Shopify Client ID and Client Secret
  3. Enter the App URL and Callback URL
  4. Enter the Webhook URL
  5. Configure scopes: read_products, read_orders, read_customers, read_inventory
  6. Click Save Settings

Shopify App Configuration

  1. Open the Shopify app configuration in the Shopify Partner dashboard
  2. Set the App URL to the same App URL configured in WhatsWay
  3. Add the WhatsWay Shopify Callback URL as the allowed redirect URL
  4. Save the Shopify app configuration

Webhook Events

  • orders/create
  • orders/updated
  • orders/fulfilled
  • customers/create
  • checkouts/create
  • checkouts/update
  • products/update — optional

Shopify does not provide a direct cart.updated webhook. Checkout events are used for abandoned cart tracking.

User Connection Process

  1. Open E-Commerce → Stores → Shopify
  2. Enter the Shopify Store URL
  3. Click Connect Store
  4. Authorize the WhatsWay application in Shopify
  5. The store connects and Shopify webhooks are registered automatically
  6. Use Sync Now to synchronize customers when required
WooCommerce

Connect using REST API credentials generated from your WordPress admin.

Required Details

  • Store URL
  • Consumer Key
  • Consumer Secret

After Connecting

  • Existing customers sync automatically
  • Connector Plugin becomes configurable
  • Webhooks enable automatically

A channel can have one store connected per platform — one Shopify store and one WooCommerce store simultaneously.

03 Customer Synchronization

The module supports both automatic and manual customer synchronization.

  • Automatic customer sync during store connection
  • Manual Sync Now option
  • Duplicate contact prevention
  • Contact update if customer information changes

05 COD Order Verification

WhatsWay automatically detects Cash on Delivery (COD) orders and verifies them through WhatsApp before processing. Customers can confirm or cancel their order with a single tap, helping reduce fake COD orders and improve delivery success rates.

Verification Features
  • Automatic COD Order Detection
  • WhatsApp COD Verification
  • One-Tap Order Confirmation
  • One-Tap Order Cancellation
  • Interactive WhatsApp Buttons
Platform Integration
  • Automatic Shopify Order Updates
  • Automatic WooCommerce Order Updates
  • COD Orders Dashboard
  • Real-Time Status Tracking
  • Automation Trigger Support

Once a customer confirms or cancels a COD order through WhatsApp, WhatsWay automatically synchronizes the updated status with Shopify or WooCommerce and can trigger additional automation workflows.

05 Automation

Supported automation triggers:

customer_created order_created order_updated abandoned_cart order_completed order_cod_pending order_confirmed order_cancelled order_paid order_fulfilled

Automations can automatically send WhatsApp templates based on these events.

The E-Commerce Module enables businesses to automate WhatsApp communication for Shopify and WooCommerce stores with customer synchronization, abandoned cart recovery, order notifications, and COD verification.
